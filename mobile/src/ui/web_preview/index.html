2. Chart Interaction Guidelines

  • Downsampled Bounded Array: The backend returns 12–25 downsampled telemetry points. Do not render hundreds of raw GPS pings.
  • Static Curve + Tap Target: Keep chart static (non-scrollable). Each waypoint node has a minimum touch target size of 32x32dp.
  • Speed Spike Logic: Render point in Amber (#F59E0B) if is_speed_spike: true.

3. Graceful Unavailable / Low-Data Logic

  • If total_distance_meters < 500 or speed_profile.length < 3, set has_low_data: true.
  • Do not throw error or display empty chart container—render the low-data banner.
