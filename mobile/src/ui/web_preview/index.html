2. Stacked Alert Visual Hierarchy

  • Tier 1 (SOS `#DC2626`): Always at top. Full-screen countdown / broadcast modal.
  • Tier 2 (Breakdown `#F59E0B`): Vehicle issue banner. Suppresses generic separation for that rider.
  • Tier 3 (Separation `#F59E0B`): Distance >500m for ≥30s. Shows capped target speed + approximate midpoint.

3. Privacy-First Medical ID Rule

Medical fields (Blood group, allergies, emergency contact) are never displayed ambiently in group rosters. They are only snapshot-attached to sos:broadcast and vehicle:breakdownReported payloads. If medical fields are omitted by the user, empty placeholder cards are strictly suppressed.
